# Almoxarifado

Projeto de controle de materiais com cadastro, listagem, baixa de estoque e exclusao usando MockAPI.

## Sprint 2

- Criada a funcao `validarRetirada(estoqueAtual, quantidadeRetirada)`.
- Adicionado botao `.btn-baixar` para retirar quantidade do estoque via PUT.
- Adicionado botao `.btn-excluir` para remover material via DELETE.
- A baixa bloqueia valores negativos, zero e quantidades maiores que o estoque atual.
